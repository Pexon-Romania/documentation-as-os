# Doc-debt register

> The graceful-enforcement ledger — **this register is canonical; STATUS mirrors the count at write-out.** Each open item is a doc that fell behind its code or reality — taken on **deliberately** (usually while gating was `relaxed`), tracked, and paid back. **Open items only** — remove each as you reconcile it.
>
> **Exact shape the hooks key on:** `- [ ] <path-or-area> — <what's stale> (<YYYY-MM-DD>)`
> Also log a **forward-looking commitment** here the moment you write it — e.g. `- [ ] confirm the restart activated the hooks (YYYY-MM-DD)` — so the gates catch it, not your memory (constitution §7).
>
> The `SessionStart` hook surfaces open items at boot · the `Stop` hook blocks once (in `strict`)
> while any remain · the `reconcile-docs` skill clears them.
