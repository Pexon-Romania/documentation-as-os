# Adopters — the estate view

Org instances of documentation-as-os. **Maintainer-kept**: adopters owe no registration — the
only report-back duty is [issues](../../issues/new/choose). Rows arrive two ways, both
zero-duty:

1. **Self-registration (one click):** the bootstrap's last step offers a prefilled
   **`[adopted]` issue** — submit it and the steward adds your row. The `adopted` label's
   timeline IS the adoption-over-time record (GitHub dates every registration for free).
2. **The census (passive):** every bootstrapped instance carries a distinctive footer stamp, so
   the steward periodically sweeps org code search for `"documentation-as-os · image"` — unregistered
   instances surface anyway (only repos the searcher can access; see MAINTAINERS).

Corrections welcome as a `suggestion` issue.

**Pre-versioned** = installed before releases existed: no stamp, no lock — the move to a
versioned image follows [`UPGRADING.md`](UPGRADING.md) §pre-versioned (a guided adoption diff,
once; ordinary upgrades ever after).

**Retired instances** (a POC that ended, a project that sunset) are ~~struck~~, never deleted —
the estate view is also the adoption history.
